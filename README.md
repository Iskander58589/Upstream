# Upstream — сайт-лендинг (черновой)

Файлы в проекте:

- `index.html` — главная страница.
- `styles.css` — стили.
- `assets/` — сюда поместите изображения (логотип, фото команды, отзывы и т.д.).

Рекомендуемые имена файлов для `assets/` (подставьте изображения, которые вы прислали):

- `logo.png` — логотип (вывеска из скриншота).
- `team.jpg` — фото команды.
- `storefront.jpg` — фото фасада/вывески.
- `camp.jpg` — фото летнего лагеря.
- `map.png` — скриншот 2GIS с адресом.
- `review1.jpg`, `review2.jpg`, `review3.jpg` — скрины отзывов/постов.

Как запустить локально:

1. Поместите файлы изображений в папку `assets/` с именами, указанными выше.
2. Откройте `index.html` в браузере (двойной клик).
